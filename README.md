# ÉcoStreaming

Outil pédagogique sur l'impact carbone du streaming vidéo et l'indice de réparabilité :
simulateur, exercices, défis et jeu vidéo.

Tous les fichiers sont au même niveau (aucun sous-dossier) : `index.html` est la page, les autres fichiers
sont les bibliothèques (Tailwind CSS, Chart.js, Font Awesome, police Inter) et leurs licences.
Le site fonctionne sans connexion à des serveurs externes.

Mise en ligne : Settings → Pages → Deploy from a branch → branche `main`, dossier `/ (root)`.
Adresse : `https://<identifiant>.github.io/<nom-du-depot>/`
